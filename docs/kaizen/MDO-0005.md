## Learn
1. **A Reviewer FAIL leaves no reason in the log** (evidence: `execution.md` T1 attempt 1 row has
   verdict `FAIL` and only an "identity mismatch" note; neither the commit `331b2d5` nor any spec
   document says what failed). The single rework of this spec cannot be analyzed. Every agent row also
   carries an "identity mismatch" note (verify-report Notes), which buries the one signal that matters.
2. **A premise read only at source was wrong; running it caught it** (evidence: MDO-0004 design P5 said
   `readModels` crashes via `modelFindings`; MDO-0005 design P3, run at `ea98793`, showed an invalid
   `models.yml` becomes an `error` finding — CC-1, resolved by the PO as option a). Without the as-run
   prototype, AC-2 would have been implemented against behavior the doctor does not have.
3. **Characterization tests have no TDD path, so the policy was improvised** (evidence: `tasks.md`
   carries an `ASSUMPTION` about TDD; `verify-report.md` reports `missingRed: [T1]` as a known exception;
   `execution.md` § Mutation evidence invents its own table). The substitute worked, but
   `kaizen-compare` now counts the spec as `no-tdd`.

## Standardize
All three approved by the maintainer's delegate (2026-10-20) and assigned to the maintainer, to be
implemented with tests in Mandao's own code and templates, outside this close (nothing in `core/` or
`src/` was edited here).

- `mandao run checkpoint` (Leader, `/mandao-implement`): a `FAIL` row must carry the Reviewer's first
  failing point in Notes, and the identity check only notes a mismatch when the model ids differ —
  approved, assigned to the maintainer.
- `/mandao-specify` premise ledger rule: a premise with impact `High` needs "as run" evidence, not
  "at source" only, or it is marked `UNVERIFIED` — approved, assigned to the maintainer.
- `.mandao/templates/app/rules/test-policy.md`: a characterization task records mutation evidence
  (mutation, failing test, assertion) in place of red, and `kaizen` counts it as `characterization`,
  not `no-tdd` — approved, assigned to the maintainer.
